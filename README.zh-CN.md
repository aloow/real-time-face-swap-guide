# 实时换脸实用指南

帮助你选择摄像头换脸方案、检查浏览器录制能力，并弄清楚结果怎样进入 OBS 或视频通话。

[English](README.md) · [浏览器检查清单（英文）](browser-checklist.md) · [OBS 与虚拟摄像头（英文）](obs-and-virtual-cameras.md) · [测试方法（英文）](testing.md)

## 先分清四个环节

1. **输入：** 工具能否接收摄像头画面？
2. **处理：** 是否持续转换新画面，延迟是否满足你的使用场景？
3. **录制：** 能否保存处理后的结果，声音是否符合预期？
4. **输出：** OBS 或通话软件能否真正接收到处理结果？

照片换脸、已有视频换脸、肖像动画和整个人物替换的工作方式不同。静态对比图、导出速度和流畅预览，都不能单独证明实时换脸的端到端表现。浏览器中能看到结果，也不能证明已经支持虚拟摄像头。

## 浏览器排错顺序

1. 确认页面处于安全上下文，检查浏览器是否提供媒体相关 API。
2. 同时检查网站摄像头权限和系统里的浏览器权限。
3. 关闭其他占用摄像头的软件，再选择正确的设备。
4. 先确认普通摄像头预览，再检查 AI 处理，最后检查保存和对外输出。
5. 先录一段短片，保存后重新播放；记录实际文件格式和声音情况。

仓库附带[浏览器能力检查器](browser-check.html)。下载后本地打开即可，不调用摄像头、不请求麦克风、不上传数据；支持中英文。GitHub 文件预览页只显示源码，不执行工具。它只能检查前置能力，不能证明 AI 换脸、录制或视频通话已经测试成功。

## 怎样提供有用的实测

记录工具版本、系统、浏览器、处理设备、模型、分辨率及输出路径；分别报告启动时间、动作延迟、持续运行、保存回放和目标软件接收情况。空白值表示未知，不记成零。完整步骤见[测试方法](testing.md)，资料出处见 [SOURCES.md](SOURCES.md)。

使用本人或已获明确授权的参考形象；通话和公开展示时说明视觉效果。反馈中不要附私人人脸图片、身份信息、会话凭据或未经同意的录屏。提交方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
